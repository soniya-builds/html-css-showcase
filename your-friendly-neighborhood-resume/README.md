# Spider-Man Portfolio Website

My first HTML and CSS project inspired by Spider-Man and cinematic Marvel-style user interfaces.

This project includes:
- Responsive layout
- Custom Spider-Man themed styling
- Dark maroon cinematic background
- Animated hover effects
- Spider-web hover interactions
- Audio and video section
- Smooth transitions and glow effects
- Fully handcrafted HTML and CSS

## Technologies Used

- HTML5
- CSS3

## Design Inspiration

Inspired by:
- Spider-Man suit aesthetics
- Marvel cinematic visuals
- Dark modern UI design

## Features

- Responsive design
- Animated cards
- Glow border hover effects
- Spider-web hover animation
- Interactive headings
- Styled media section
- Custom gradients and shadows

## How to View

1. Download or clone the repository
2. Open the project folder
3. Run the `index.html` file in your browser

You can also use the VS Code Live Server extension for a better viewing experience.
